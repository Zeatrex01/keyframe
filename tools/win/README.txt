Keyframe Studio for Windows
===========================

Start: double-click "Keyframe Studio.exe". The studio opens in its own window; closing the
window stops it. Node is bundled, so nothing else has to be installed for the studio itself.

Install (optional): double-click "Install.cmd". It copies the app to
%LOCALAPPDATA%\Programs\Keyframe Studio, adds Start menu and desktop shortcuts and an entry in
Settings > Apps to remove it. No administrator rights are needed.

Your projects stay wherever you keep them. Settings, the project list and logs live in
%LOCALAPPDATA%\Keyframe Studio, outside the app folder, so updating or removing the app
never touches them.

Updates: Settings > About shows when a new version is out and installs it after you confirm.
The download is checked against the checksum published with the release.

The AI: the studio's built-in Director runs the agent program you already use (Claude Code,
Codex or Gemini CLI). Install and sign in to one of them separately.

First start: the app is not signed, so Windows SmartScreen may say "Windows protected your
PC". Choose "More info" and then "Run anyway".
